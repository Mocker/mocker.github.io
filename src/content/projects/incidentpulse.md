# IncidentPulse

Modern incident management software is enterprise-priced and bloated for solo developers and small teams. IncidentPulse is a lightweight, self-hostable incident command center:

- **Instant webhook ingress** — receives and normalizes alerts from Sentry, Stripe, GitHub Actions, AWS, and uptime pingers.
- **Realtime war room** — a live triage room with shared notes, chat, and status streaming over Serverpod WebSockets.
- **Smart escalation ladder** — background workers page responders when critical issues go unacknowledged.
- **Pluggable AI telemetry bridge** — structured incident context for autonomous agents, not just humans.
